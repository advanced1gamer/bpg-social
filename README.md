# bpg-social

Image hosting for [@black.point.gaming](https://www.instagram.com/black.point.gaming) on Instagram.

| Folder | What's in it |
|---|---|
| `library/media/` | Source images (`M###-name.jpg`). Catalog: `library/media.json` |
| `library/reference/` | Near-duplicates kept for reference only. Never posted. |
| `graphics/` | Approved master graphics (`G-...jpg`). Catalog: `graphics/graphics.json` |
| `posts/YYYY-MM/YYYY-MM-DD-AM\|PM/` | Exactly what went (or is going) to Instagram: `01.jpg`, `02.jpg`, … plus `post.json` |

Only approved content is committed here. Adding media: **Add file → Upload files** into `library/media/`, named like `operator-headset-profile.jpg`.
